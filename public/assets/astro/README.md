# Astro artwork

Sign coins (`sign-*.webp`) and graha spheres (`planet-*.webp`), 256 and 512 px.

- Source: Magnific (formerly Freepik) premium stock, downloaded by the project owner. Keep the licence PDFs outside the repo for as long as the subscription is active.
- Processed for the app: background-removal specks cleaned, glow trimmed to the shape, converted to WebP.
- Licence limits: never use these in the app icon, logo or any trademark. Use one artwork per screen at rest (design.md glow rule) and never below about 40 px.
